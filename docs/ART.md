# 立绘与镜头

舞台上一个人有几种画法，用途不同，补齐的先后也不同。

## 三层

| 层 | 文件 | 用在哪 | 画法 |
| --- | --- | --- | --- |
| 像素 | `{id}.png`、`{id}-{expr}.png` | 全场 | 限色、面积降采样、最近邻放大 |
| 线稿 | `{id}-line-{expr}.png` | 特写、回忆 | 细线、非像素、留白 |
| 镜头 | `{id}-closeup.png`、`{id}-memory.png` | 某一格专用的整张 | 按那一格单独画 |

三层不是三套美术，是同一份设计的三次落笔：像素是常态，线稿是靠近，镜头图是那一格只出现一次的画。

## 命名

```
{角色}-{镜头}.png        特写或回忆，整张
{角色}-line-{表情}.png    线稿按表情
{角色}-{表情}.png         像素按表情
{角色}.png                像素常态，一定存在
```

表情五种：`neutral`、`happy`、`unhappy`、`surprised`、`ember`。
镜头两种：`closeup`、`memory`。

## 缺哪张退哪张

服务端给的是**候选列表**，从最具体排到一定存在的那一张：

1. `{id}-{shot}.png` —— 这一格专用的
2. `{id}-line-{expr}.png` —— 线稿按表情
3. `{id}-{expr}.png` —— 像素按表情
4. `{id}.png` —— 一定有

舞台依次试，第一张能加载的就是这一格该用的图。所以素材可以一张一张补，任何时刻舞台都是完整的，不会出现空洞。

## 什么时候推近

镜头由结算结果决定，不由观众选：

| 发生了什么 | 镜头 |
| --- | --- |
| 说了真话 | 特写 |
| 看穿了别人 | 特写 |
| 被人看穿 | 特写 |
| 失名（忘了谁） | 回忆 |
| 其余 | 全场 |

回忆压过特写。失名是这部戏里唯一一件不能演出「发生」、只能演出「记得」的事，所以它换的不是距离，是画法。

## 每人一套十二张

```
{id}.png                1
{id}-{expr}.png         4      happy unhappy surprised ember
{id}-line-{expr}.png    5      含 neutral
{id}-closeup.png        1
{id}-memory.png         1
```

跑 `scripts/check-art.ps1` 看现在有几张、缺哪几张。它不依赖服务：角色名就是 `assets/portraits` 里那些不带 `-` 与 `_` 的 png。

## 为什么不用连续的表情

立绘管线只能画有限张图。一个「六成三高兴」的角色画不出来，而假装能画的系统最后永远显示同一张脸。所以表情是五个槽，谁现在是哪一格由结算决定——同一场戏重放，看到的还是同一组脸。
